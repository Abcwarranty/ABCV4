# Policy Pilots Coming Soon WordPress Theme

A modern, minimalist coming soon page theme for Policy Pilots - Your AI co-pilot for smarter insurance decisions.

## Features

- **Responsive Design** - Looks great on all devices
- **Email Subscription** - Collect email addresses with AJAX form submission
- **Admin Dashboard** - View and export subscribers from WordPress admin
- **Customizable** - Easy customization through WordPress Customizer
- **SEO Optimized** - Clean, semantic HTML structure
- **Accessibility Ready** - WCAG compliant with proper ARIA labels
- **Performance Optimized** - Lightweight and fast-loading

## Installation

1. Download the theme files
2. Upload to `/wp-content/themes/policy-pilots-coming-soon/`
3. Activate the theme in WordPress admin
4. Customize through Appearance > Customize

## Customization

### Theme Customizer Options

- **Coming Soon Settings**
  - Main Title
  - Description Text
  
- **Email Settings**
  - Admin Notification Email
  - Success Message

### Logo

Upload your logo through Appearance > Customize > Site Identity > Logo

## Email Subscribers

- View subscribers: Appearance > Subscribers
- Export to CSV available
- Admin email notifications for new subscriptions
